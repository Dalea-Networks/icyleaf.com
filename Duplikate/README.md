# Duplikate

Hier liegen Dateien, die bit-identisch (gleiche MD5-Summe) an einer zweiten
Stelle im Projekt vorhanden sind und an **dieser** Stelle von keiner Seite
referenziert werden.

Die Ordnerstruktur unterhalb ist die ursprüngliche, damit jede Datei bei
Bedarf zurückgelegt werden kann:

    Duplikate/uploads/2022/08/12/…  →  uploads/2022/08/12/…

Vollständige Gegenüberstellung samt aktiv genutzter Variante:
siehe `../KATEGORISIERUNG.md`, Abschnitt „Duplikate".

**Nicht enthalten:** die drei identischen HTML-Weiterleitungen unter
`2022/02/` — sie sind aktive URLs und wurden absichtlich stehen gelassen.
